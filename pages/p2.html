MPFB

Human character generator and editor.
Add-on by Joel-Palmius
About What's New Permissions Reviews Version History

MPFB is a free and open source character generator for Blender. It builds complete humans - body, face, skin, eyes, hair, clothes, rig and weight painting - directly in the viewport. No subscription, no account, no hidden paid premium tier. The addon is GPL and the asset packs are CC0 or CC-BY, so what you make is yours, commercial work included.

Getting more information

  • Getting started (text version): install, add assets, and make your first character. About ten minutes.
  • Getting started (video version) if you prefer watching a video over reading the textual introduction.
  • Documentation: Explanation of core concepts and a description of the system
  • FAQ: Answers to frequently asked questions

Asset packs: install "MakeHuman system assets" first

MPFB ships with a small built-in set of assets so the download stays reasonable. Everything else, such as skins, eyes, hair, clothes, proxies, poses, expressions, are free separate downloads from the asset packs page.

If you only download one, make sure it is MakeHuman system assets. It holds the skins, eyes, teeth and proxy meshes that the other libraries assume you already have. If the asset libraries look empty, you are probably missing this asset pack.

To install a pack: MPFB tab → Apply assets → Library settings → Load pack from zip file, pick the zip you downloaded, then restart Blender. The getting started tutorial shows this step with screenshots.

What MPFB does

  • One click from nothing to a rigged, textured, animation-ready human
  • Parametric modelling: age, weight, muscle, height and proportions, plus detailed sliders for face and body shape
  • Automatic rigging with a choice of rigs, including Rigify, with IK and FK
  • Procedural skin and eye materials
  • Asset library for clothes, hair, body parts, materials, poses and expressions
  • Standard Blender meshes and armatures throughout — export to Mixamo, Unity, Unreal or Godot the usual way
  • Optional: read assets and characters from an existing MakeHuman installation

What MPFB is not

MPFB is a parametric modelling tool, not a library of scanned photoreal humans. Every character starts from the same base mesh and is shaped by you, and the supplied skins and hair are hand-made rather than photoscanned. If you want a catalogue of finished photoreal people, other tools do that better. If you want to build characters yourself, keep the source, and pay nothing, that is what this is for.

Getting support

If you run into trouble, you are always welcome to open a support ticket.

Project

Developed by the MakeHuman Community. MPFB is a spiritual successor of the MakeHuman desktop application, implemented as a Blender extension. It uses the same asset formats as the original MakeHuman

# How an idea round runs

Three agents, not more, unless Cody says otherwise. Sonnet, high effort.

1. **Main session** reads `daily/LESSONS.md`, `daily/DISCUSSED.md` and Cody's brief for the round. It does not read the whole idea journal.
2. **Two inventors**, run together, each on a different angle from the brief. Each reads `daily/LESSONS.md`, `daily/DISCUSSED.md` and `daily/SCORECARD.md`, gets up to 15 searches, and returns ONE idea as a filled scorecard, under 350 words.
3. **One checker**, run after the inventors, given both scorecards. Its only job is to knock them down: search for existing versions, open the links, test the numbers. Up to 15 searches. It returns a verdict per idea, under 250 words. It does not propose ideas.
4. **Main session** reports to Cody: the survivor (or "neither stood"), the scorecard, the checker's verdict, and the cheapest test. If that test can be run in the session for little cost, offer to run it.
5. **Journal it**: a short section in `daily/IDEA-JOURNAL.md`, a line in `daily/DISCUSSED.md`, a line in `daily/LESSONS.md` only if something new was learned, and `notes/STATE.md`.

Do not use any Ubersuggest tool (daily quota is spent). Never the words "ship" or "shipping".
